# agent/ — quién es Donna

`identity.md` es la identidad de Donna: quién es, qué hace, qué no hace, cómo responde y qué no
comparte. Es la **única fuente** de esa identidad:

- `@donna/agent-client` la mete en cada mensaje al agente (`npm run identity` la convierte en código).
- El bot de Telegram la manda igual.
- Fue la primera lección con la que se entrenó al agente.

Cambiarla cambia cómo responde Donna en todas partes: hazlo por PR y avisa a Brian, que vuelve a
entrenar al agente con la versión nueva.
